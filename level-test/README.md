# Level tests

The two free English level tests on biradimileri.com:

| Page | ID | Built with | What it is |
|---|---|---|---|
| `/seviye-testi` | 1688 | Elementor (one HTML widget in `_elementor_data`) | 11-question self-assessment, browser only |
| `/seviye-testi-40` | 4011 | Gutenberg `wp:html` block in `post_content` | 40-question CEFR placement test (A1→C2), result emailed via `POST /wp-json/bai/v1/level-test` |

The pages say they were generated by `tools/build-v2-leveltests.py`, which is not in this repo. Edit the page
content directly. In the inline script, avoid `&&`, `//` comments and a literal `<` in strings (write `\x3C`).

## Changes on staging (17 Oct 2026), page 4011 only, not yet on live

1. **Encouragement screens:** one message for each finished level (A1, A2, B1, B2, C1). Before, the index was off,
   so the last two messages never showed and "Yarı yoldasın" appeared at question 28 of 40. The messages are now
   about progress, not performance (the old ones praised everyone, even after all "I don't know" answers). The
   badge line also shows how many questions are done, e.g. `B1 bölümü tamamlandı · 21/40 soru · sırada B2`.
2. **No more "certificate":** the result now shows a **Seviye rozeti** (the existing level titles, e.g. "B1 İletişimci").
   The print button reads "Sonucunu yazdır / PDF kaydet", and the note says the badge is not an official document.
   The share text includes the badge. *No* "register to keep your badge" prompt yet: accounts can't store
   badges until the account feature in `PLAN.md` exists, and promising it now would be untrue.

Not changed on request: the `/deneme-sinavlari` line that says the 40-question test covers reading.

### Undo on staging
```bash
python3 - <<'EOF'
import json, os, subprocess
body = json.dumps({"content": open("level-test/backup/staging-4011-seviye-testi-40-2026-10-17.html").read()})
subprocess.run(["curl", "-s", "-o", "/dev/null", "-w", "%{http_code}\n", "-u", os.environ["WP_USER"] + ":" + os.environ["WP_STAGING_APP_PASSWORD"],
  "-X", "POST", "-H", "Content-Type: application/json", "--data", body,
  os.environ["WP_STAGING_URL"] + "/wp-json/wp/v2/pages/4011"], check=True)
EOF
```

## Placement rule study

`tools/placement_sim.py` simulates 40,000 learners on a Rasch model with some residual guessing, using our item
layout (7/7/7/7/6/6). It compares the current rule with alternatives. See `PLAN.md` §1.
